关于 Vue3 组合式 API 的思考

admin · 2026-04-21 · 公开区

Vue3 引入的组合式 API（Composition API）解决了 Options API 在大型组件中逻辑分散的问题……

核心优势

  • 逻辑复用通过自定义 composable 函数实现
  • 相关逻辑聚合，不再分散在各 option

setup() 是入口，ref/reactive 是状态，watch/computed 是派生逻辑。
